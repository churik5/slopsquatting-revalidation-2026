## Notes

- `npm_standard_malicious_code_text`: npm's standard README (the package contained malicious code and was removed by the npm security team).
- `npm_standard_description_only`: npm's standard description `security holding package` with an empty README; the text itself does not give the reason, the OSV column does.
- `other_text_publisher_placeholder`: version `0.0.1-security` but the publisher's own text (a name reservation), not npm's.
- `request_failed_no_response`: no response to the allowed request(s).
- Extra requests are stored in `registry_checks` as round `meta`: npm_registry 16 rows (HTTP 200; errors: ConnectTimeout); osv 2 rows (HTTP 200; errors: none). The latest row per name is used.
